# HR Dashboard

An interactive Tableau dashboard for exploring employee demographics, workforce composition, compensation, departments, performance ratings, and employee records.

## Live Dashboard

[Open the HR Dashboard on Tableau Public](https://public.tableau.com/views/HRDashboard_17917961678960/HRSummary?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

## Project Overview

This project turns an employee dataset into an interactive HR analytics experience. The dashboard supports workforce exploration through summary views, employee records, and filters for understanding patterns across departments, locations, education levels, job titles, salaries, and performance ratings.

## Key Questions

- How is the workforce distributed across departments and locations?
- Which job titles and departments have the highest salaries?
- What patterns appear in employee performance ratings?
- How do active and inactive employee records compare?
- How can HR teams inspect individual employee details efficiently?

## Tools

- Tableau Public and Tableau Desktop
- CSV data preparation
- Interactive dashboard filters and navigation
- Git and Git LFS for project version control

## Dataset

`Dataset.csv` contains employee-level records with fields including:

- Employee ID
- Name and gender
- State and city
- Education level
- Birthdate, hire date, and termination date
- Department and job title
- Salary
- Performance rating

## Running the Project

1. Download or clone this repository.
2. Open `HR Dashboard.twbx` in Tableau Desktop.
3. Use the dashboard filters and navigation controls to explore the analysis.
4. Alternatively, open the [published Tableau dashboard](https://public.tableau.com/views/HRDashboard_17917961678960/HRSummary?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link) in a browser.

The Tableau Desktop installer is intentionally not included because it is a large executable. Install Tableau Desktop separately from the official Tableau website if you need to edit the workbook.
